# Drip Dots

A p5.js remix of [Okazz's sketch on OpenProcessing](https://openprocessing.org/@okazz/2625827).
The drips follow the phone's tilt, or the mouse position on desktop.

Live: https://tarmelop.github.io/drip-dots/

Shake the phone to shuffle the dots. On desktop: `s` shuffles, `1`–`5` try different trajectories, `d` toggles the tilt indicator.
